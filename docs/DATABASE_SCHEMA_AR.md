# تصميم قاعدة البيانات

## الكتالوج

- `categories`: تصنيفات المنتجات.
- `products`: الاسم الرسمي والسعر الموحد ووحدة البيع ومعلومات العميل.
- `product_aliases`: الأسماء الشائعة وأخطاء النطق والكتابة.
- `product_price_history`: تاريخ كل تعديل للسعر.
- `catalog_imports`: بصمة كل نسخة كتالوج تم استيرادها.
- `branch_product_availability`: التوفر حسب الفرع، منفصل عن السعر الموحد.

## الفروع والسياسات

- `branches`: الخرج والدلم وبيانات التحويل والنطق.
- `business_hours`: ساعات العمل لكل فرع.
- `business_policies`: السياسات المعتمدة التي يسمح للوكيل بذكرها.

## خدمة العملاء

- `conversations`: بيانات الجلسة وملخص المكالمة دون تخزين صوت.
- `service_requests`: الشكاوى وطلبات الاتصال والمتابعة.
- `order_drafts`: رأس مسودة الطلب.
- `order_draft_items`: بنود المسودة مع Snapshot للسعر والاسم.

## الحوكمة

- `tool_audit`: كل أداة نفذها الوكيل، مع إخفاء البيانات الحساسة.
- `admin_audit`: تغييرات الإدارة.

بيانات الاسم والجوال والعنوان في الطلبات تُخزن مشفرة باستخدام AES-256-GCM، ويُخزن Hash مستقل للجوال عند الحاجة إلى البحث دون فك جميع البيانات.
